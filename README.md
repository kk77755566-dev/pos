# Girls Bar POS

ガールズバー向けPOSシステムの開発リポジトリです。店舗単位のデータ分離を前提に、MySQL 8 + FastAPI + ブラウザ操作画面で構築しています。

## 構成
- `tax.html`: 既存の簡易会計計算ページ（内容を変更せず保全）
- `database/schema.sql`: MySQL 8初期スキーマ
- `backend/app/main.py`: 認証・POS・会計・勤怠・給与・日締めAPI
- `backend/scripts/bootstrap_store.py`: 初期店舗・オーナー作成
- `backend/tests/`: 計算単体テストとMySQL結合テスト
- `frontend/index.html`: iPad・スマートフォン・PC向け操作画面
- `frontend/validate.mjs`: フロントエンド構文・DOM要素検査
- `docs/`: 要件・画面/API仕様・セットアップ手順

## 実装済みの主な機能
- ログイン、店舗単位のデータ分離、CORS許可オリジン制御
- 卓・着席・セット登録・商品注文
- 注文明細ごとのキャストバック配分
- 会計表示、分割支払い、冪等キー
- 一部・全額返金、返金履歴、返金理由・監査ログ
- 出勤・退勤、勤務時間丸め、時給＋バックの仮給与計算・確定
- 整合性チェック付き日締め（未精算卓・未退勤・未確定給与はブロック）
- 商品・セット・キャスト・卓の登録・編集・無効化API
- 店舗税率・サービス料・勤務時間丸め設定

## 店舗ルール
- セット・延長料金は店舗単位で設定
- 商品ごとに標準バック率・方式を設定し、注文ごとに配分先を選択
- 給与は時給＋バックを基本とする
- 勤務時間の丸め単位・方式は店舗設定
- 税・サービス料の計算方式は店舗設定
- 日締めは集計後に整合性チェックを行い、問題がある場合は確定しない

## 開発・検証
開発ブランチは `feature/girlsbar-pos-foundation` です。GitHub ActionsではPython構文、フロントエンドJavaScript、MySQL 8スキーマ適用、初期店舗作成、API結合テストを検証します。

## 本番利用前の必須確認
- 日本の最低賃金、深夜割増、時間外割増、法定休憩、税・源泉徴収などの法令対応は未認証です。給与確定APIは現時点では暫定計算です。
- 実店舗のDB・ネットワーク・複数端末での受入試験が必要です。
- 決済端末・カード会社への返金実行はPOS内の返金台帳登録とは別作業です。実際の返金操作・照合手順を店舗運用に合わせて確認してください。
- 本ブランチは開発用です。mainへのマージ・本番公開はしていません。
- 既存DBへ適用する場合はバックアップとマイグレーションを用意してください。schema.sqlは新規DB向けです。
