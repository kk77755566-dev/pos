# Girls Bar POS

ガールズバー向けPOSの開発リポジトリです。

## 現在の構成
- `tax.html`: 既存の簡易会計計算ページ（保全。後続の会計UI移行時に参照）
- `database/schema.sql`: MySQL 8.0初期スキーマ
- `docs/requirements.md`: 業務要件・確定ルール
- `docs/api-screen-spec.md`: API・画面の初期詳細設計

## 確定した店舗ルール
- 基本セット・延長料金：店舗ごとに自由設定
- 商品バック：商品ごとの標準バック率、注文の商品明細ごとに付与先を選択
- 給与：時給＋バック
- 勤務時間：15分単位（丸め方式は店舗設定）
- 税・サービス料：店舗ごとに自由設定
- 日締め：自動集計後、整合性チェック成功時に自動確定。エラー時は保留

## DB初期化
新規の空DBに対して `database/schema.sql` をMySQL 8.0で実行してください。既存DBへの無検証適用はしないでください。

## 注意
- 本ブランチは開発用です。mainへのマージ・本番公開は行っていません。
- 初期スキーマはレビューとMySQL実機テストが必要です。
- 給与計算は最低賃金、深夜割増、時間外割増、休憩等の法令要件を確認してから本番運用してください。
